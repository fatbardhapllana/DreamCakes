# DreamCakes 🍰

## Përshkrimi
DreamCakes është një aplikacion e-commerce ku përdoruesit mund të shikojnë tortat 🍰, t'i shtojnë në shportë 🛒 dhe t'i blejnë lehtësisht 💳.

## Teknologjitë 💻
- **Laravel** – për backend dhe menaxhimin e databazës
- **React** – për frontend dhe ndërfaqen interaktive të përdoruesit
- **TailwindCSS** – për dizajn modern dhe të personalizueshëm të ndërfaqes
- **MySQL** – për ruajtjen e të dhënave të produkteve dhe porosive

## Funksionalitetet kryesore ✨
- Shikimi i tortave të disponueshme 🍰
- Shtimi i produkteve në shportë 🛒
- Procesi i blerjes online 💳
